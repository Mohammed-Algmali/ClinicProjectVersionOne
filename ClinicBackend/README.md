# نظام إدارة العيادات والمستشفيات (SaaS Clinic System - Backend)

هذا هو المشروع الخلفي (Backend) لنظام إدارة العيادات والمستشفيات، والمصمم للعمل كمنصة برمجية كخدمة **(SaaS)** تدعم تعدد المستأجرين **(Multi-Tenancy)** لخدمة عدة عيادات بشكل معزول وآمن.

## التقنيات المستخدمة (Tech Stack):
- **الإطار البرمجي:** FastAPI (Modern Approach)
- **قاعدة البيانات:** PostgreSQL
- **أداة الهجرات:** Alembic

## المعمارية البرمجية (Software Architecture):
تم اعتماد **العمارة القائمة على الوحدات والميزات (Feature-Driven / Module-Based Architecture)** لضمان مرونة النظام وقابليته للتوسع الضخم، حيث يتم عزل كل وحدة برمجية بشكل مستقل.

### هيكل مجلدات المشروع الحالي:
- `alembic/`: إدارة وإصدار هجرات وتعديلات قاعدة البيانات.
- `app/core/`: يحتوي على الإعدادات العامة ونظام الحماية والاتصال بقاعدة البيانات.
- `app/core/middleware/`: البرمجيات الوسيطة (مثل إدارة وعزل بيانات العيادات تلقائياً).
- `app/modules/`: المجلد الرئيسي لكافة ميزات النظام (مثل: auth, clinics, patients) حيث تحتضن كل وحدة الـ Models والـ Routers والـ Repositories الخاصة بها.
- `app/main.py`: نقطة انطلاق التطبيق وتجميع واجهات برمجية التطبيقات (APIs).
- `.env`: ملف المتغيرات البيئية الحساسة (بيانات الاتصال والتشفير).
- `requirements.txt`: ملف حزم ومكتبات بايثون المطلوبة للتشغيل.
